# segmentacion-geoespacial-trafico-movil-qro
Tesis para el obtener el grado de Ingeniero en Comunicaciones y Electrónica. Esta tesis busca proporcionar una metodología robusta y replicable que pueda ser utilizada por autoridades reguladoras y operadores de telecomunicaciones en la evaluación de la calidad de tráfico móvil utilizando técnicas de Machine Learning.
